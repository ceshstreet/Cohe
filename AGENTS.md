# Working on Corporacion CoHe

Read README.md before editing. This project is a Spanish-language sales landing page for a digital forensics reseller and integrator in El Salvador.

- Follow the current React, TypeScript, Vite, Three.js and Lucide patterns.
- Keep changes scoped to the requested work and preserve existing user changes.
- Keep the corporate identity as Corporacion CoHe, using the accented spelling in visible Spanish content.
- Check src/App.tsx, src/index.css and index.html for current application behavior and presentation.
- Keep the Three.js scene responsive and dispose of WebGL resources and object URLs when appropriate.
- Local video selection is a browser preview, not a persistent upload service. The contact form uses mailto, not a backend.
- Do not claim specific partner relationships or replace provisional contact details without confirmed information.
- Run pnpm test and pnpm build. For visual changes, inspect the page at desktop and mobile sizes.
- Preserve LICENSE and THIRD_PARTY_NOTICES.md when redistributing.
- Keep credentials out of source, public files and commits. Environment files and node_modules are ignored.
- Deployments and remote writes require user authorization.

The docs directory, legacy automotive components and reference-manifest.json describe the original VEYRA release, not the current landing page. Do not restore that release unless explicitly requested. The verify:reference script checks the original baseline and is not an acceptance check for CoHe.
